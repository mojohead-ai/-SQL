## Неделя 1: Основы SQL и простые запросы

### Теоретический блок
- **Введение в SQL**: что такое SQL, реляционные базы данных, СУБД
- **Структура SQL-запроса**: базовый синтаксис, ключевые слова
- **Оператор SELECT**: выбор столбцов, псевдонимы (AS)
- **Предложение WHERE**: простые условия сравнения (=, <>, >, <, >=, <=)
- **Сортировка ORDER BY**: ASC, DESC, сортировка по нескольким полям
- **Базовые функции**: UPPER, LOWER, LENGTH, ROUND

### Практический трек
Работаем с базой данных интернет-магазина:
1. **Просмотр каталога товаров**: получить список всех товаров с ценами, отсортированный по названию
2. **Фильтрация клиентов**: найти всех клиентов из определенного города
3. **Анализ заказов**: показать заказы на сумму больше 1000 рублей, отсортированные по дате

### Контроль усвоения
**Вопрос**: Напишите запрос для получения имен и email всех клиентов из Москвы, отсортированных по фамилии в алфавитном порядке.

<details>
<summary>Ответ</summary>

```sql
SELECT first_name, last_name, email
FROM customers
WHERE city = 'Москва'
ORDER BY last_name ASC;
```
</details>

## Неделя 2: Фильтрация и сортировка данных

### Теоретический блок
- **Расширенная фильтрация WHERE**: логические операторы (AND, OR, NOT)
- **Оператор LIKE**: поиск по шаблону (%, _)
- **Операторы IN и BETWEEN**: работа с множествами и диапазонами
- **Работа с NULL**: IS NULL, IS NOT NULL, особенности NULL в сравнениях
- **DISTINCT**: исключение дубликатов
- **LIMIT/TOP**: ограничение количества строк

### Практический трек
1. **Поиск товаров**: найти все товары, названия которых содержат слово "телефон" или "смартфон"
2. **Анализ активности клиентов**: получить уникальные города клиентов, которые совершили заказы в последние 30 дней
3. **ТОП-продажи**: показать 10 самых дорогих товаров в категории "Электроника"

### Контроль усвоения
**Вопрос**: Как найти всех клиентов, у которых нет указанного телефона, но есть email, и они живут в Санкт-Петербурге или Екатеринбурге?

<details>
<summary>Ответ</summary>

```sql
SELECT *
FROM customers
WHERE phone IS NULL 
  AND email IS NOT NULL 
  AND city IN ('Санкт-Петербург', 'Екатеринбург');
```
</details>

## Неделя 3: Агрегатные функции

### Теоретический блок
- **Агрегатные функции**: COUNT, SUM, AVG, MIN, MAX
- **GROUP BY**: группировка данных, правила группировки
- **HAVING**: фильтрация групп (отличие от WHERE)
- **Комбинирование группировки**: несколько полей в GROUP BY
- **Вычисляемые поля**: арифметические операции в SELECT

### Практический трек
1. **Статистика по категориям**: подсчитать количество товаров и среднюю цену в каждой категории
2. **Анализ клиентской базы**: найти топ-5 городов по количеству активных клиентов
3. **Выручка по месяцам**: рассчитать общую сумму заказов по месяцам за текущий год

### Контроль усвоения
**Вопрос**: Напишите запрос для получения категорий товаров, где средняя цена больше 5000 рублей, и покажите количество товаров в каждой такой категории.

<details>
<summary>Ответ</summary>

```sql
SELECT c.category_name, COUNT(p.product_id) as products_count, AVG(p.price) as avg_price
FROM products p
JOIN categories c ON p.category_id = c.category_id
GROUP BY c.category_name
HAVING AVG(p.price) > 5000;
```
</details>

## Неделя 4: Соединения таблиц (JOIN)

### Теоретический блок
- **Концепция JOIN**: связи между таблицами, первичные и внешние ключи
- **INNER JOIN**: получение связанных данных
- **LEFT JOIN**: включение всех записей из левой таблицы
- **RIGHT JOIN**: включение всех записей из правой таблицы
- **FULL OUTER JOIN**: полное соединение
- **Множественные JOIN**: соединение более двух таблиц

### Практический трек
1. **Детализация заказов**: получить информацию о заказах с данными клиентов и товарах
2. **Анализ продаж по клиентам**: показать каждого клиента с общей суммой его покупок
3. **Неактивные товары**: найти товары, которые ни разу не были заказаны

### Контроль усвоения
**Вопрос**: Как получить список всех категорий товаров с количеством проданных единиц в каждой категории, включая категории без продаж?

<details>
<summary>Ответ</summary>

```sql
SELECT c.category_name, COALESCE(SUM(oi.quantity), 0) as total_sold
FROM categories c
LEFT JOIN products p ON c.category_id = p.category_id
LEFT JOIN order_items oi ON p.product_id = oi.product_id
GROUP BY c.category_name;
```
</details>

## Неделя 5: Подзапросы и вложенные конструкции

### Теоретический блок
- **Типы подзапросов**: скалярные, строчные, табличные
- **Подзапросы в WHERE**: сравнение с результатом подзапроса
- **Операторы EXISTS и NOT EXISTS**: проверка существования связанных данных
- **Операторы ANY, ALL, SOME**: сравнение с множественными значениями
- **Подзапросы в SELECT и FROM**: вычисляемые поля и виртуальные таблицы

### Практический трак
1. **VIP-клиенты**: найти клиентов, сумма заказов которых превышает средний чек по всем клиентам
2. **Анализ конкурентности**: определить товары, цена которых выше средней в их категории
3. **Активные категории**: найти категории, в которых были продажи в текущем месяце

### Контроль усвоения
**Вопрос**: Напишите запрос для поиска клиентов, которые совершили заказы на сумму больше любого заказа клиентов из Москвы.

<details>
<summary>Ответ</summary>

```sql
SELECT DISTINCT c.*
FROM customers c
JOIN orders o ON c.customer_id = o.customer_id
WHERE o.total_amount > ANY (
    SELECT o2.total_amount
    FROM orders o2
    JOIN customers c2 ON o2.customer_id = c2.customer_id
    WHERE c2.city = 'Москва'
);
```
</details>

## Неделя 6: Оконные функции

### Теоретический блок
- **Концепция оконных функций**: OVER(), PARTITION BY, ORDER BY
- **Ранжирующие функции**: ROW_NUMBER(), RANK(), DENSE_RANK()
- **Агрегатные функции с окном**: SUM() OVER, AVG() OVER, COUNT() OVER
- **Функции смещения**: LAG(), LEAD(), FIRST_VALUE(), LAST_VALUE()
- **Накопительные итоги**: ROWS и RANGE в оконных функциях

### Практический трек
1. **Рейтинг товаров**: создать рейтинг товаров по продажам внутри каждой категории
2. **Динамика продаж**: показать ежемесячную выручку с накопительным итогом
3. **Сравнение с предыдущим периодом**: сравнить продажи текущего месяца с предыдущим для каждого товара

### Контроль усвоения
**Вопрос**: Как найти для каждого заказа клиента дату его предыдущего заказа и разницу в днях между заказами?

<details>
<summary>Ответ</summary>

```sql
SELECT 
    customer_id,
    order_date,
    LAG(order_date) OVER (PARTITION BY customer_id ORDER BY order_date) as prev_order_date,
    order_date - LAG(order_date) OVER (PARTITION BY customer_id ORDER BY order_date) as days_between_orders
FROM orders
ORDER BY customer_id, order_date;
```
</details>

## Неделя 7: Модификация данных

### Теоретический блок
- **INSERT**: добавление новых записей, bulk insert
- **UPDATE**: изменение существующих данных, условные обновления
- **DELETE**: удаление записей, каскадное удаление
- **UPSERT/MERGE**: вставка или обновление
- **Транзакции**: BEGIN, COMMIT, ROLLBACK, ACID-принципы
- **Ограничения**: PRIMARY KEY, FOREIGN KEY, UNIQUE, CHECK

### Практический трек
1. **Управление каталогом**: добавить новые товары, обновить цены существующих
2. **Обработка заказов**: создать новый заказ с несколькими позициями в транзакции
3. **Архивирование данных**: перенести старые заказы в архивную таблицу

### Контроль усвоения
**Вопрос**: Как в одной транзакции добавить нового клиента и сразу создать для него заказ, при этом откатить все изменения если что-то пошло не так?

<details>
<summary>Ответ</summary>

```sql
BEGIN TRANSACTION;

INSERT INTO customers (first_name, last_name, email, city)
VALUES ('Иван', 'Петров', 'ivan@email.com', 'Москва');

INSERT INTO orders (customer_id, order_date, total_amount)
VALUES (LAST_INSERT_ID(), CURRENT_DATE, 1500.00);

-- Если все прошло успешно:
COMMIT;

-- Если произошла ошибка:
-- ROLLBACK;
```
</details>

<details>
<summary>Ответ</summary>
