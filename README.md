# Создание промпта план изучения SQL

## Вариант 1 (плохой)

Напиши план изучения SQL.

## Вариант 2 (средний)

Я новичок и хочу выучить SQL для работы с базами данных. Составь для меня пошаговый план обучения на 2 месяца. Добавь туда информацию про основные команды, фильтрацию данных и объединение таблиц. Желательно, чтобы в плане были практические задания.

## Вариант 3 (отличный)

Действуй как Senior Database Engineer и профессиональный преподаватель IT-курсов. Составь для меня детализированный пошаговый план изучения SQL с полного нуля до уровня уверенного пользователя (Middle).

Мои ресурсы: Я могу выделять на учебу 4 часа в неделю (2 занятия по 2 часа) в течение 2 месяцев (всего 8 недель).

Структура плана: Разбей план строго по неделям. Для каждой недели распиши:

1. Теоретический блок: какие конкретно конструкции, операторы или концепции нужно освоить (от простых SELECT/WHERE на первой неделе до JOIN, группировок GROUP BY, подзапросов, оконных функций и индексов на последующих).
2. Практический трек: придумай для каждой недели по 3 сквозных практических задания на примере вымышленной базы данных интернет-магазина (например, написать запрос на поиск топ-5 покупателей, расчет выручки по категориям и т.д.).
3. Контроль усвоения: один главный вопрос или мини-тест для самопроверки в конце недели.

Требования к оформлению: Излагай материал последовательно, от простого к сложному. Используй разметку Markdown, таблицы для недельного расписания и оформляй примеры SQL-кода в специальные блоки кода. Пиши на русском языке, избегай лишней "воды", сфокусируйся на применимости навыков.
